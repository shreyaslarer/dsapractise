# DSA Practice Tracker

This repository contains small C++ programs for basic data-structure and sorting practice.

It is also a structured repository for my **Data Structures and Algorithms** practice, maintained for interview preparation and problem-solving improvement.

## Files included
- `quicksort.cpp`
- `mergesort.cpp`
- `bubblesort.cpp`
- `insertionsort.cpp`
- `selectionsort.cpp`
- `hashing.cpp`
- `charhashing.cpp`
- `mapcharfreq.cpp`
- `mapintfreq.cpp`
- `learn.cpp`
- `ld.cpp`

## Why this repository?

I built this repository to:

- Practice DSA consistently
- Strengthen core problem-solving patterns
- Track progress topic-wise
- Prepare for coding interviews with optimized solutions

## What you will find here

- Topic-wise problem organization
- Clean and readable code
- Multiple approaches where relevant
- Time and space complexity notes
- Regular updates as I solve new problems
