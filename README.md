# Practice Algorithms

This repository contains small C++ programs for basic data-structure and sorting practice.

Files included:

- `bubblesort.cpp`
- `insertionsort.cpp`
- `selectionsort.cpp`
- `hashing.cpp`
- `charhashing.cpp`
- `mapcharfreq.cpp`
- `mapintfreq.cpp`
- `learn.cpp`
- `ld.cpp`

Each file is a separate example or exercise.
